像素顏色替換

1. 上傳圖片
尚未上傳圖片
2. 要替換的原顏色
尚未選取 請直接點擊圖片上的顏色
直接點右側圖片即可吸取該位置的原始像素顏色。
3. 替換成什麼顏色
#FF0000 所有符合條件的像素都會變成此顏色
4. 顏色容差
容差 0
0 = 只替換 RGB 完全一樣的像素。提高後，和原顏色接近的像素也會一起替換。
5. 周圍像素覆蓋
把符合像素的周圍也塗成新顏色
px
可輸入到小數點後兩位；小數部分會按比例混合最外圈像素。
預覽
原始符合： 0 像素
最終覆蓋： 0 像素
